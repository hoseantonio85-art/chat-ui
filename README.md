# Universal Agent UI Pilot

Интерактивный UI-пилот универсального AI-чата НОРМ. Он показывает нового агента внутри существующего продуктового интерфейса: историю диалогов, компактный статус работы, раскрываемый технический trace, источники, субагентов, ошибки, файлы, таблицы и графики.

Данные и ответы в этой версии демонстрационные. Подключение к production API не требуется.

## Локальный запуск

Нужны Node.js 18 или новее и npm.

```bash
cd pilot
npm ci
npm run dev
```

Откройте:

- UI-пилот: <http://127.0.0.1:4410/>;
- интерактивную карту сценариев: <http://127.0.0.1:4410/scenario-map/>.

## Проверка сборки

```bash
cd pilot
npm run typecheck
npm test
npm run build
```

## Публикация GitHub Pages

Публикация всегда собирается из исходников ветки `universal-agent-ui-pilot`. Минифицированные файлы в `gh-pages` вручную не редактируются.

```bash
cd pilot
npm ci
npm run deploy:pages:dry-run # проверить состав артефакта без push
npm run deploy:pages         # проверить, собрать и заменить gh-pages одним коммитом
```

Скрипт использует временный `git worktree`, копирует только содержимое `pilot/dist`, добавляет `.nojekyll` и публикует результат в корень ветки `gh-pages`. Для project Pages сборка выполняется с базовым путём `/chat-ui/`. Одна multi-page сборка публикует чат по `/chat-ui/` и карту по `/chat-ui/scenario-map/`; deploy завершается ошибкой, если отсутствует любое из двух приложений или экранные снимки карты.

## Карта сценариев

MVP карты связывает два представления одних и тех же шагов:

- текстовую карту сценария;
- экранный canvas со снимками реальных состояний UI-пилота и живым HTML-просмотром в масштабе 100%.

Снимки сохраняют быструю обзорную карту, а кнопка «Открыть 100%» загружает соответствующее воспроизводимое состояние самого пилота в изолированном `iframe`. Состояние задаётся параметром `atlas`, например `/chat-ui/?atlas=vnd.result&embed=1`.

В MVP разложены фоновая проверка ВНД и удаление факта памяти в настройках. Структура и критерии описаны в [`docs/SCENARIO_MAP_MVP.md`](docs/SCENARIO_MAP_MVP.md).

## Доступные сценарии

- обычная проверка;
- работа с экспертом;
- источник без данных;
- источник недоступен;
- файл, таблица и график;
- регистрация события;
- обычный чат без формы.
- проверка ВНД в фоне с индикаторами в истории и сохранением через диалог.

Исходные компоненты продукта находятся в `src`, а автономная демонстрационная оболочка и mock-сценарии — в `pilot`.
