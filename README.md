# Universal Agent UI Pilot

Интерактивный UI-пилот универсального AI-чата НОРМ. Он показывает нового агента внутри существующего продуктового интерфейса: историю диалогов, компактный статус работы, раскрываемый технический trace, источники, субагентов, ошибки, файлы, таблицы и графики.

Данные и ответы в этой версии демонстрационные. Подключение к production API не требуется.

## Локальный запуск

Нужны Node.js 18 или новее и npm.

```bash
cd pilot
npm ci
npm run dev
```

Откройте:

- UI-пилот: <http://127.0.0.1:4410/>;
- интерактивную карту сценариев: <http://127.0.0.1:4410/scenario-map/>.

## Проверка сборки

```bash
cd pilot
npm run typecheck
npm test
npm run build
```

## Публикация GitHub Pages

Публикация всегда собирается из исходников ветки `universal-agent-ui-pilot`. Минифицированные файлы в `gh-pages` вручную не редактируются.

```bash
cd pilot
npm ci
npm run deploy:pages:dry-run # проверить состав артефакта без push
npm run deploy:pages         # проверить, собрать и заменить gh-pages одним коммитом
```

Скрипт использует временный `git worktree`, копирует только содержимое `pilot/dist`, добавляет `.nojekyll` и публикует результат в корень ветки `gh-pages`. Для project Pages сборка выполняется с базовым путём `/chat-ui/`. Одна multi-page сборка публикует чат по `/chat-ui/` и карту по `/chat-ui/scenario-map/`; deploy завершается ошибкой, если отсутствует любое из двух приложений или экранные снимки карты.

## Карта сценариев

MVP карты связывает два представления одних и тех же шагов:

- текстовую карту сценария;
- экранный canvas со снимками реальных состояний UI-пилота и живым HTML-просмотром в масштабе 100%.

Снимки сохраняют быструю обзорную карту, а кнопка «Открыть 100%» загружает соответствующее воспроизводимое состояние самого пилота в изолированном `iframe`. Состояние задаётся параметром `atlas`, например `/chat-ui/?atlas=vnd.result&embed=1`.

В MVP разложены фоновая проверка ВНД, удаление факта памяти, разговорный CSI после ВНД и по запросу, жалоба, помощь, идея и похвала. Карта содержит 54 воспроизводимых состояния. Структура карты описана в [`docs/SCENARIO_MAP_MVP.md`](docs/SCENARIO_MAP_MVP.md), контракт feedback-агента и будущая frontend-задача подключения API — в [`docs/CSI_PROTOTYPE.md`](docs/CSI_PROTOTYPE.md).

Правила и история решений по интерфейсу собираются в [летописи UX](docs/UX_DECISIONS.md). В папке «Формат ответа» есть интерактивный сценарий «Варианты выбора и действия» с готовой перепиской для проверки прокрутки.

## Доступные сценарии

- обычная проверка;
- работа с экспертом;
- источник без данных;
- источник недоступен;
- файл, таблица и график;
- регистрация события;
- обычный чат без формы.
- проверка ВНД в фоне с индикаторами в истории и сохранением через диалог.
- CSI после проверки ВНД и по инициативе пользователя: 1–5, необязательный комментарий, отказ, mock success/error;
- жалоба, запрос помощи, идея и похвала с максимум одним уточнением о сервисе и сохранением точных реплик.

Исходные компоненты продукта находятся в `src`, а автономная демонстрационная оболочка и mock-сценарии — в `pilot`.

## Прототип точек входа ВНД TO-BE

Отдельная страница: `/chat-ui/vnd/`. Главная и база знаний используют обезличенные скриншоты с HTML-областями клика. Клик по полю главной или иконке документа открывает пустой чат; ввод в поле с клавиатуры и Enter передаёт запрос в чат. Кнопки проверки открывают приветственный сценарий. Меню и первая новость ведут в базу знаний, иконка Норма открывает пустой `vndToBe`. Используется тот же `App` и `ModalContainer`, без второго экземпляра чата.

Скриншоты масштабируются вместе с областями клика. При ширине менее 760px доступна горизонтальная прокрутка для сохранения читаемости макета. Данные, показатели и новости — демонстрационные; имена в исходном изображении главной обезличены, исходный экран новостей с профилем не публикуется.

Workflow `Publish VND prototype` проверяет типы, сценарии, сборку, переходы и закрытия в Chromium, затем запускает `npm run deploy:pages` из исходной ветки. Отчёт со снимками сохраняется в артефакте workflow.

ВНД: плюс на карточке «Стандарты» открывает «Загрузка документов». Баннер ведёт в чат; выбор/перетаскивание файла и «Отправить на проверку» передают вложение тому же чату. Для ветки без отклонений откройте /chat-ui/vnd/?review=clean#knowledge или выберите «ВНД to be · без отклонений» в сценариях UI-пилота. После успешной проверки и повторной проверки папка по умолчанию — «Стандарты». Файлы и сохранение демонстрационные, остаются в памяти браузера.
