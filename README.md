# Universal Agent UI Pilot

Интерактивный UI-пилот универсального AI-чата НОРМ. Он показывает нового агента внутри существующего продуктового интерфейса: историю диалогов, компактный статус работы, раскрываемый технический trace, источники, субагентов, ошибки, файлы, таблицы и графики.

Данные и ответы в этой версии демонстрационные. Подключение к production API не требуется.

## Локальный запуск

Нужны Node.js 18 или новее и npm.

```bash
cd pilot
npm ci
npm run dev
```

Откройте <http://127.0.0.1:4410/>.

## Проверка сборки

```bash
cd pilot
npm run typecheck
npm test
npm run build
```

## Доступные сценарии

- обычная проверка;
- работа с экспертом;
- источник без данных;
- источник недоступен;
- файл, таблица и график;
- регистрация события;
- обычный чат без формы.

Исходные компоненты продукта находятся в `src`, а автономная демонстрационная оболочка и mock-сценарии — в `pilot`.
